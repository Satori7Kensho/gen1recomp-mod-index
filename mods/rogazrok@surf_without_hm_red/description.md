# Modern Field Moves

Modern Field Moves brings modern HM and field-move quality-of-life features to Pokémon Red, Blue, Yellow, Gold, Silver and Crystal on gen1recomp, while keeping the classic look and feel of the original games.

Pokémon no longer need to sacrifice moveslots just to use HMs in the overworld. Field moves become natural world interactions while the original progression requirements remain intact by default.

## Features

- Contextual CUT, SURF, STRENGTH, WHIRLPOOL and WATERFALL
- TOWN MAP / MAP integration for Fly
- Contextual LIGHT system for dark areas
- Manual and automatic lighting modes
- Configurable HM requirements
- Generic, known-move and first-party field-move user modes
- Optional confirmation prompts
- Debug-friendly UNRESTRICTED mode
- Support for Red, Blue, Yellow, Gold, Silver and Crystal

## Compatibility

Modern Field Moves modifies field-move logic, menus, maps and some world interactions.

Core functionality has been tested, but rare edge cases involving scripted events, story flags or unusual progression states may still exist.

Compatibility with other mods has not been extensively tested. Mods that modify field moves, the START menu, Town Map / Pokégear map, Flash/lighting or related world logic may conflict.

Keeping a backup of your save file is recommended.
